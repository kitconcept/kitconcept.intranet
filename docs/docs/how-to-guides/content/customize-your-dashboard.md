# Customize your dashboard

This guide shows you how to open your personal dashboard and change its blocks.

## Prerequisites

- You are logged in.
- A Person in the intranet is linked to your user account. If the
  **Dashboard** link is missing from your user menu, ask an administrator to
  {doc}`create your Person <create-person>`.

## Steps

### 1. Open your dashboard

In the toolbar, open your user menu and click **Dashboard**.

```{image} /_static/images/dashboard-user-menu-link.png
:alt: The user menu in the toolbar with the Dashboard link
:width: 600px
:align: center
```

Until you have edited your dashboard, it shows the default layout that your
administrators set up for everyone.

```{image} /_static/images/dashboard-default-layout.png
:alt: A dashboard showing the default layout, with only the Edit button in the toolbar
:width: 600px
:align: center
```

### 2. Start editing

Click the **Edit** button (pencil icon) in the toolbar.

The first time, this creates your own copy of the default dashboard and opens
it in the editor.

### 3. Change the blocks

Change the dashboard like any other page, for example:

- Add a block, such as a listing or a teaser.
- Remove a listing that you don't need.
- Select a listing and change its headline, criteria or number of items in the
  sidebar.
- Drag blocks to change their order.

```{image} /_static/images/dashboard-edit-form.png
:alt: A dashboard open in the block editor
:width: 600px
:align: center
```

### 4. Save

Click **Save** in the toolbar.

## Verification

To confirm your changes were saved:

1. Open your user menu and click **Dashboard** again.
2. Your dashboard shows your changes.

## Notes

- Your dashboard is private. Only you and site administrators can see it.
- Your changes affect only your own dashboard.
- Each save creates a new version. To restore an earlier one, open the
  dashboard's **History**.
- Changes that administrators make to the default layout later don't change your
  dashboard.
